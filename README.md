# README

## Repository

This is the URL to the repository: [https://github.com/Maksym-Tkachuk/back-kultprosvet.git](https://github.com/Maksym-Tkachuk/back-kultprosvet.git).

## Installation

To set up and install all the dependencies for this project, please follow these steps:

1. Ensure you have [Node.js](https://nodejs.org/) and [Yarn](https://yarnpkg.com/) installed on your machine.

2. Clone the repository and navigate to the project folder:

   ```bash
   git clone https://github.com/Maksym-Tkachuk/back-kultprosvet.git
   cd back-kultprosvet
   ```

3. Install all dependencies by running the following command:

   ```bash
   yarn
   ```

## Environment Setup

In the root directory, you will find a `.env.example` file containing the required environment variables. Use this file as a reference to create a `.env` file with the necessary configurations.

## Starting the Application

To start the application in development mode, use the following command:

```bash
yarn start:dev
```

This will start the server, and you can access it at [http://localhost:3000](http://localhost:3000).

## Accessing the Deployed Server

You can access the deployed server at the following URL:

[https://back-kultprosvet-production.up.railway.app](https://back-kultprosvet-production.up.railway.app)

## Running Tests

- To start end-to-end (E2E) tests, use the following command:

  ```bash
  yarn test:e2e
  ```

- To start unit tests, use the following command:

  ```bash
  yarn test
  ```
